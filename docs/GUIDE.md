# «Учёт работ» — как пользоваться и сопровождать

Приложение для Android. Мастера вносят выполненные работы, руководитель оценивает
работы вне прайса, смотрит сводки и выгружает отчёт в Excel.

## Где что находится
| Что | Где |
|---|---|

## Новый сотрудник
1. **Руководитель** в приложении: «Сотрудники» → «+ Добавить сотрудника» (или выбрать
   существующего) → логин и пароль («Придумать пароль») → «Создать вход».
   Записать логин и пароль, передать сотруднику.
2. **Сотрудник** на своём телефоне открывает ссылку на APK (или сканирует QR-код),
   устанавливает: «Настройки» → «Разрешить из этого источника» → «Установить».
   При предупреждении Play Защиты — «Подробнее» → «Всё равно установить».
3. Входит своим логином. Пароль больше не спрашивается, пока не нажать «Выйти».

Уволился сотрудник — «Сотрудники» → он → «Отключить сотрудника». Войти он больше не сможет,
его работы остаются в отчётах. Забыл пароль — там же «Сменить пароль».

## Обновления приложения
* **Обычные изменения** (экраны, тексты, логика) приходят на телефоны сами:
  открыть приложение → подождать 10–20 секунд → закрыть полностью → открыть снова.
* **Новый APK** нужен, только если в приложение добавляется новый «встроенный» модуль
  телефона (так было один раз — для меню «Поделиться»). Тогда всем сотрудникам нужно
  установить новый файл поверх старого; данные и вход сохраняются.

Для Claude (из облачной сессии):
```bash
cd app && set -a && . ./.env && set +a
npx eas-cli@latest update --branch preview --environment preview --message "что изменилось" --platform android --non-interactive
npx eas-cli@latest build --platform android --profile preview --non-interactive --no-wait   # только когда нужен новый APK
```
Изменения базы — файлы в `supabase/migrations/`, применяются по порядку; серверные функции —
`npx supabase functions deploy <имя> --use-api`. Проверки: `bash supabase/tests/run.sh`.

## Ограничения бесплатных тарифов
* **Supabase Free** ставит проект на паузу после 7 дней без единого запроса. При ежедневной
  работе этого не случится; после долгих праздников — открыть supabase.com → проект →
  «Restore». На бесплатном тарифе нет удобных резервных копий: раз в месяц выгружайте
  Excel за месяц (это полная копия журнала с ценами) или перейдите на платный тариф Pro.
* **Expo Free**: есть месячные лимиты на сборки APK и на число телефонов, получающих
  обновления; для команды из 5–10 человек их хватает с запасом.

## Работа из России
Серверы Supabase и Expo работают через Cloudflare. Сейчас приложение работает и через
Wi-Fi магазина, и через мобильный интернет. Если провайдеры начнут резать соединения
(симптом: «Нет связи с сервером» при живом интернете), решение — свой адрес-посредник
на российском хостинге перед Supabase; приложение для этого почти не меняется.

## Чего пока нет
* **Загрузка нового прайса файлом** (xlsx/csv с предпросмотром и датой начала действия) —
  понадобится для прайса 2027. Сейчас цены меняются по одной позиции в «Прайс».
  Отложено по решению заказчика до появления цен 2027 года (11.10.2026). Потребуется новый APK
  (модуль выбора файла на телефоне).
* **iPhone**: код общий, но для установки нужен аккаунт Apple Developer (99 $/год).

## Проверка требований (критерии готовности)
| Требование | Как проверено | Итог |
|---|---|---|
| Найти работу среди 1 399 позиций ≤ 10 с; смена из 5 работ < 2 мин | поиск отвечает < 1 с; сценарий с 2 работами — 8 с автоматом; проверено заказчиком на телефоне | ✓ |
| Работа вне прайса ≤ 30 с и не попадает в отчёты до оценки | тесты базы 04, 05; экран «На оценке» | ✓ |
| Мастеру не приходят цены и суммы отдельных работ | аудит 25 запросов под мастером на рабочем сервере, 11.10.2026; RLS-тесты | ✓ |
| *Изменение 11.10.2026 по решению заказчика:* мастер видит итоги — свои и коллег — по месяцам (раздел «Команда») и свою сумму за месяц на главной | тест 06 | ✓ |
| Сумма в приложении = сумма в Excel до копейки | выгрузка за год: 4 листа = «Сводка» | ✓ |
| Сумма долей исполнителей = стоимость работы | тесты 03–05 (в т.ч. 28,57 ₽ на троих) | ✓ |
| Помесячные итоги истории = старый файл | август 321 880, сентябрь 890 000, октябрь 360 450 | ✓ |
| Excel открывается без предупреждений, диаграммы редактируются | проверено заказчиком в Excel; LibreOffice, openpyxl | ✓ |
| Android и iOS из одной кодовой базы | Android — APK; iOS — код общий, сборка не делалась (нет iPhone) | Android ✓ |
