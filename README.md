# Учёт работ

Мобильное приложение (Android) для учёта работ специалистов по ремонту в магазине:
мастера закрывают смену, руководитель оценивает работы вне прайса, смотрит сводки
и выгружает отчёт в Excel с диаграммами.

* `docs/GUIDE.md` — как пользоваться и сопровождать (начните отсюда)
* `docs/RUN.md` — что проверялось на каждом этапе, ссылка на APK
* `docs/PLAN.md` — схема базы и экраны
* `app/` — приложение (Expo, React Native, TypeScript)
* `supabase/` — база (миграции, права доступа), серверные функции, скрипты загрузки, тесты
* `data/` — исходный прайс 2026 и старый файл учёта
