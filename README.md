# Учёт работ

Мобильное приложение для учёта работ мастеров по ремонту в магазине.

* `app/` — приложение (React Native + Expo, TypeScript)
* `supabase/` — база данных: миграции, правила доступа, серверные функции, тесты
* `docs/PLAN.md` — план, схема базы, экраны
* `docs/RUN.md` — как запустить и что проверить
* `price_2026_max.csv`, `uchet_rabot_2026_ishodnik.xlsm` — исходные данные
